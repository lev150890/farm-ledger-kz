# Учёт хозяйства Амиржанов

Мобильное приложение для учёта поголовья, расходов и доходов хозяйства. Все суммы указываются в казахстанских тенге (₸). Есть отдельные группы животных: КРС, бараны и овцы, козы, куры, лошади.

## Как пользоваться

1. Для локального просмотра запустите `node server.js` из этой папки и откройте `http://127.0.0.1:8765/`. Файлы отдаются без кэширования, поэтому после изменений достаточно обновить вкладку.
2. Для доступа на телефоне опубликуйте папку приложения на HTTPS-хостинге. На Android откройте HTTPS-адрес в Chrome и выберите **«Установить приложение»** или **«Добавить на главный экран»**. Приложение откроется отдельно и сохранит оболочку для работы без сети.
3. В разделе **«Поголовье»** задайте число животных каждого вида.
4. В разделе **«Сезоны»** настройте автоматический ежедневный расход на одну корову. Летняя ставка действует в выбранном промежутке пастбищного сезона, зимняя — в остальные дни года. Итог считается по текущему поголовью КРС и отображается в годовой сводке, графике, статье расхода и отчёте.
5. В разделе **«Статьи»** создайте, переименуйте или удалите статьи доходов и расходов. Для каждой статьи можно выбрать значок. При переименовании связанные записи в журнале обновятся; используемую статью нельзя удалить, пока к ней привязаны записи.
6. Нажмите **«Добавить запись»**, выберите группу животных, тип операции, статью, дату и сумму. Каждая сохранённая запись сразу учитывается в годовой сумме доходов или расходов. Описание необязательно.
7. Для регулярного расхода нажмите **«Выбрать несколько дат»** в форме записи. Отметьте нужные дни в календаре одного года: на каждый день создастся отдельная запись с той же суммой. В форме показываются количество дат и общая сумма.
8. Выберите год, чтобы посмотреть годовую выручку, расходы и итог. Кнопка **«Скачать отчёт»** выгружает журнал в CSV для Excel.

Расходы включают сено, корма и зерно, воду, ветеринарию, сарай и стойло, оборудование, электричество, транспорт, услуги и другие траты. Доходы включают продажу молока, сливок, сметаны, творога и другой молочной продукции.

Записи можно изменить или удалить из журнала. Данные и поголовье хранятся локально на устройстве; синхронизации между телефонами пока нет. Для Google Play потребуется опубликовать PWA по HTTPS и упаковать её в Android App Bundle (например, через Trusted Web Activity), а затем пройти публикацию в Play Console.
